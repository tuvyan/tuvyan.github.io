Visual Article Editor

Edit articles and publish directly to GitHub Pages.

Important: Publishing uses a GitHub fine-grained personal access token with Contents: Read and write permission for this repository only. Your token stays in this browser tab and is not saved by the editor. The Studio page itself is public; never share your token or enter it on an untrusted site.

Edit heritage pages

For new articles, choose a unique URL filename; the editor will create the HTML page and update both catalogues.

The public address will be https://tuvyan.github.io/your-article-title.html. Choose the filename before adding media.

Title & Metadata

These details update both the article page and the homepage catalogue when published. Existing archival evidence is preserved.

Article categories (select one or more)

The first selected category is the primary category. Existing selections are preserved until you change them.

Leave the date blank if uncertain. An original publication date is different from the date you edited the webpage.

Archive evidence will appear here after the article loads. Do not treat an archive timestamp as a verified first-publication date.
Selected photograph Only the webpage display changes. The original photograph file stays intact.

Crop photograph (original preserved)

Change the visible framing only. The source photograph is never edited or replaced.

Drag the blue crop rectangle, its corners, or its edges to choose the visible area. The sliders remain available for legacy framing. Rotation remains separate.

Insert / Upload

Place the cursor in the article first, then choose files. Files are uploaded to the public GitHub repository when you publish. Maximum 20 MB per file; use external hosting for larger videos. Check permissions and privacy before publishing.

Click a photograph to adjust its display. Click directly in a caption to edit it. Images are previewed from their actual article folders. Existing image filenames and paths are preserved when publishing. Always download a backup before major edits.

For safety, use a fine-grained token restricted to tuvyan.github.io with Contents: Read and write. The token is held only in this tab; close the tab to discard it. Never commit it to your repository.
