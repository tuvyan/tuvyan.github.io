TUVYAN Comment Moderation Manager

Review submissions received by email, then publish approved comments to the website.

1. Connect to your GitHub repository

Use a fine-grained token with Contents: Read and write permission for tuvyan/tuvyan.github.io. The token is kept only in this page's memory, not saved in the website or browser storage.

2. Approve a comment

Copy the display name and comment from the FormSubmit email. Never paste passwords or private email details. This tool does not automatically read your inbox.

Adding to draft does not publish anything. Review the draft below before clicking Publish.

3. Review and publish

Load the existing comments first.

Publication updates only guest-comments/approved-comments.json. Existing article pages and the dictionary forum remain untouched.
