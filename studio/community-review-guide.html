Community Review Workflow

Editorial guide only. This page does not import GitHub Discussions, contact contributors, or change dictionary data.

1. Receive

Read new submissions in TUVYAN GitHub Discussions. Check for privacy concerns, cultural restrictions, respectful language, and sufficient context. Avoid copying private contributor information into public records.

2. Evaluate

Compare the proposed word or spelling with existing entries and documented usage. Note dialect/community context, pronunciation, and supporting evidence. Ask for clarification in the discussion if necessary.

3. Record editorial decision

Open the Vinanaw Editorial Review Workspace and record the proposal. Use Proposed → Under Review → Approved or Rejected. Keep a JSON backup. Never treat a community post as an automatic approval.

4. Publish approved entries

Export the editorial JSON backup, open the Dictionary Publication Review, inspect the approved entries, and manually upload dictionary/entries.json to GitHub. Verify the public dictionary.

5. Respond and correct

Where appropriate, reply to the original discussion with a brief editorial outcome. Keep attribution and permission decisions explicit. For a disputed entry, revise the editorial record before the next public export.

Important: The editorial workspace saves locally in the browser. Back up its JSON file regularly; public dictionary exports intentionally exclude private evidence and notes.
