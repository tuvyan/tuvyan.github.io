Suggested workflow

  1. Choose the Article Editor for a post or Special Page Editor for a permanent page.
  2. Save and download a draft backup while writing.
  3. Review dates, categories, and related reading in the Editorial Dashboard.
  4. Run publication checks and inspect the live page after committing changes.

Security: These URLs are public. Do not put passwords, personal access tokens, confidential records, or private community submissions into an untrusted browser session. Access controls must be implemented separately if needed.
