4. How to restore safely

  1. Download the current article HTML from your GitHub repository and keep it as a rollback backup.
  2. Select an earlier version above and download its HTML. Review its text, photos, date, and links carefully.
  3. To restore it, replace only the matching HTML file in the GitHub repository, preserving the original filename. Commit with a descriptive message.
  4. Refresh the published article and check the article body, historical photos, publication date, and related-reading links.
  5. If anything looks wrong, restore your saved current HTML or use GitHub's commit history to recover it.

This tool never requests a GitHub access token. It does not read or recover unfinished local drafts from the Visual Editor.
