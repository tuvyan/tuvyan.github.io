Welcome to your one-stop editorial workspace

Use the left-hand menu to open an editor directly inside this dashboard. You no longer need to remember each tool's address or keep many tabs open.

  1. Articles & essays: edit existing posts or create new ones, including heritage articles.
  2. Heritage & special pages: update permanent pages while preserving their layout.
  3. Vinanaw: manage lexical drafts, then review approved dictionary exports.
  4. Photography: maintain the public photography catalogue.
  5. Version history: inspect published GitHub revisions before restoring manually.

Important: This is one unified interface, not yet a single shared editor or database. Each tool retains its own save and export controls. If an embedded tool does not work as expected, choose Open separately.
