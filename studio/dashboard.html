How to publish safely
  • Keep a backup of your repository before bulk updates.
  • Use the article and page editors for content; use catalogue tools for dates and relationships.
  • Confirm GitHub Actions and GitHub Pages deployments after committing changes.
  • Preserve original archival photographs, citations, author notes, and historical dates.
