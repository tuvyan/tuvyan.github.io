Vinanaw Dictionary — Publication Review

1. Import your editorial backup

Export a JSON backup from the Vinanaw Editorial Review Workspace, then choose it here. This tool only prepares a publication file; it never uploads or publishes automatically.

No file selected.

2. Review approved entries

Privacy and provenance: Only the word, type, variant, pronunciation, and meaning are exported. Contributor identities, source notes, editorial notes, and private evidence are excluded. Review every approved entry for accuracy and publication permission.

3. Publish to GitHub

After downloading, rename nothing. Upload the file as dictionary/entries.json to your TUVYAN GitHub repository, replacing the previous dictionary data file. Commit and verify the public dictionary page.

This process is intentionally manual. It does not grant community members publishing rights.
