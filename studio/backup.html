Backup & Recovery

Protect TUVYAN's articles, family photographs, musical scores, scanned documents and website code. This page is a guide; backups run on GitHub, not in your browser.

1. Download a backup now

Open GitHub's repository menu and choose Code → Download ZIP. Save the ZIP to your computer and another independent location.

Open repositoryView dated backup releases

2. Check automatic backups

After the backup workflow is installed, it runs weekly on Sundays (UTC), and you can run it manually from Actions. Each successful run creates a dated GitHub Release with a ZIP, checksum and file manifest.

Run or check backup workflow

On the workflow page, choose Run workflow to create your first backup. If the workflow fails when publishing a release, check Settings → Actions → General → Workflow permissions → Read and write permissions.

3. Keep an independent copy

  1. Download the latest dated backup ZIP and its .sha256 file from Releases.
  2. Save copies on your computer and a separate external drive or cloud account.
  3. Check that the ZIP opens and contains articles.json, photos, PDFs and the music-archive folder.
  4. Repeat monthly and after major website changes.

4. Recover safely

  1. Do not delete the current repository or overwrite it immediately.
  2. Download and verify a backup, then compare its contents with the current repository.
  3. Restore only missing or damaged files first, preserving newer work.
  4. Commit changes and check the published site after deployment.

What is not covered?

These backups cover files committed to GitHub. They do not automatically include the full Git revision history, unpublished local files, comments held by external providers, social media, streaming audio hosted elsewhere, or private credentials. For complete Git history, periodically run git clone --mirror https://github.com/tuvyan/tuvyan.github.io.git and store that mirror separately.

GitHub Releases are useful for dated copies but are still stored within GitHub. Keep at least one independent offline or cloud backup.
